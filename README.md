# SWYNEX - Data Cleaning & Preparation

## Task 1: Data Cleaning & Preparation

This project demonstrates the process of cleaning and preparing a dataset using Python and Pandas.

## Dataset

Dataset used: Iris Dataset

The dataset contains information about:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Data Cleaning Steps

The following data cleaning techniques were performed:

1. Identified missing values
2. Filled missing numerical values using median
3. Filled missing categorical values using mode
4. Identified and removed duplicate rows
5. Converted data types where required
6. Standardized inconsistent categorical values
7. Saved the cleaned dataset as CSV

## Tools & Technologies

- Python
- Pandas
- Scikit-learn
- Google Colab

## Files

- `iris_cleaned.csv` - Cleaned dataset

The dataset was cleaned and prepared for further data analysis and machine learning tasks.
